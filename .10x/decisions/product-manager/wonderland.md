# Product Manager - wonderland

## Users
Recruiters/hiring managers (need facts fast), engineering peers (SAGE depth), curious visitors (exploration).

## User stories (MVP = all must-haves from plan §18)
1. As a recruiter I can reach About, Experience, Projects, Contact and CV within 2 clicks (quick nav / Classic mode).
2. As a visitor I can walk the world with WASD or click-to-move and never fall off or get stuck.
3. As a visitor I always know where to go: minimap, world map, guide trail, signposts, compass.
4. As a visitor I can see which objects are interactive and open their info with E / click / tap.
5. As a mobile visitor I can use a joystick or tap-to-travel and read bottom-sheet panels.
6. As a returning visitor the intro is skipped automatically.
7. As the owner I can add a project / role / skill / award by editing one content file.

## Success criteria
- First screen states name + headline. Every content section is reachable without walking.
- All facts match plan.md; unknown links are hidden.
- Classic mode works without WebGL; 3D runs at 30fps or better on mid-range laptops (low tier available).

## Out of scope
Plan §19. Additional projects only once supplied by the owner.
